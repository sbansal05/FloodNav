# FloodNav

FloodNav is a flood-aware evacuation routing project that demonstrates how road closures can affect evacuation routes.

## Simulated Flood Scenarios

The road closures in Levels 1, 2, and 3 are simulated for demonstration purposes and do not represent verified real-world flood conditions. They were selected along the tested route from the default starting node (`6722487558`) to demonstrate how increasing road closures affect route availability and distance.

The scenarios illustrate evacuation routing under different hypothetical flood conditions. They are not real-time flood predictions.

## Route Testing

The routing system was tested from the default starting node (`6722487558`) to Camp 1 (`566643822`).

| Scenario | Route distance |
|---|---:|
| No flooding | 6,197 m |
| Level 1 | 6,630 m |
| Level 2 | 7,676 m |
| Level 3 | 9,705 m |

These results demonstrate how simulated road closures can change the selected evacuation route.
